# BL-003 - Instance Conservatory

**Payoff:** build a repeated structure by changing a parameter instead of copying objects manually.

**Mechanism:** an inspectable Geometry Nodes graph creating an array. Exposed inputs control the repeated result; generated geometry is evaluated by Blender.

**Try:** inspect the node links, change Experiment value, apply it, and compare the evaluated result. In a saved copy, modify spacing or source shape and explain the effect before applying the graph.

**Reset:** reset restores the owned graph and scene baseline.

**Automated gate:** evaluate at more than one input and verify the expected geometry/result difference. **Editor gate:** inspect sockets and links, manipulate the control, and distinguish instances from realized geometry. **Visual gate:** the repeated arrangement communicates rhythm and scale.

**Limit:** glTF exports evaluated geometry, not the editable Geometry Nodes graph. A small array passing does not establish large-scene memory/performance behavior or arbitrary node compatibility.

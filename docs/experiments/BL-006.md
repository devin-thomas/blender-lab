# BL-006 - Portable Artifact

**Payoff:** learn what an interchange file actually preserves by exporting a bounded object and inspecting the reimport.

**Mechanism:** selected glTF export, fresh reimport, and declared geometry/transform comparisons. The editable Blender source remains the authoring authority.

**Try:** inspect the source object, export it, inspect the artifact path, reimport, and compare mesh properties and appearance. Record which attributes were checked rather than assuming all Blender data survived.

**Reset:** reset restores the source fixture; regenerate local export/reimport artifacts intentionally.

**Automated gate:** confirm artifact creation, successful reimport, and the bounded mesh contract. **Editor gate:** inspect both versions and the operator's output/error behavior. **Downstream gate:** import into a named engine version with explicit material/sampling and transform checks.

**Limit:** modifiers, procedural node graphs, rigid-body settings, and arbitrary material nodes are not portable editable mechanisms in glTF. A Blender roundtrip establishes only its inspected contract; Godot acceptance remains separate.

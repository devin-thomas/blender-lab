All checks below are target acceptance requirements for this specified capability. None is claimed executed by this card or by the existence of an API lead.

- Cancelled job reaches terminal cancelled state and releases its worker slot
- Diagnostics identify failure layer/source while completed artifacts remain traceable

Negative and recovery outcomes:

- Timeout cannot publish a completed-success receipt
- Retry uses a new job identity and cannot overwrite an unrelated output

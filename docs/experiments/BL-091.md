## Qualification

All checks below are target acceptance requirements for this specified capability. None is claimed executed by this card or by the existence of an API lead.

Positive outcomes:

- Authorized allowed request produces a correctly identified isolated job
- Result/artifact retrieval checks ownership and completed-state identity

Negative and recovery outcomes:

- Unauthenticated or arbitrary-code request is rejected before worker launch
- Path traversal or unauthorized artifact lookup cannot reach unrelated files

Execution profiles: `local`, `external`.

Preview budget: One original mesh, scene, clip or job envelope; inspect the local artifact before invoking a receiver.

Qualification budget: Two positive cases and two failures using a named receiver/runtime; maximum 256 MiB artifact per case.

Hard limit: No credentials, account or network is required for the public baseline; external/profile failures remain explicit.

**Fallback:** Run the identical versioned task locally through CLI.

Limits:

- Blender has no general first-party cloud modeling API
- A local service specification is not deployed network qualification

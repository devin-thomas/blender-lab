# BL-005 - Gravity Bench

**Payoff:** distinguish an authored starting pose from a simulated result by dropping an original rigid object onto a passive surface.

**Mechanism:** Blender rigid-body world, active/passive bodies, collision shapes, and forward frame evaluation.

**Try:** inspect body roles and collision settings, play from the first frame, then change the exposed input and compare the drop. Scrubbing backward may involve cache behavior; restart at the first frame for a reproducible test.

**Reset:** reset restores owned objects/world and the starting frame. Save hand-authored variations separately.

**Automated gate:** evaluate forward in sequence and compare simulated movement against initial position with a stated tolerance. **Editor gate:** play, reset, and inspect physics properties. **Visual gate:** the falling object and contact surface remain readable.

**Limit:** Blender rigid-body output does not prove Godot physics parity. Simulation caches/tolerances are version-sensitive; a small drop does not qualify high-speed collision, stacking, or large simulations.

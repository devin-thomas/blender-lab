# BL-001 - Silhouette Foundry

**Payoff:** learn which edges deserve geometry by changing an original workshop object's profile and modifier response.

**Mechanism:** authored mesh data and a non-destructive modifier stack. Generated topology remains editable; the evaluated object shows the effect of modifiers.

**Try:** build the baseline, view its outline from the camera and side, change Experiment value, apply it, and compare the stack and evaluated mesh. Save a copy, then move one vertex by hand and watch what changes.

**Reset:** reset the owned lab scene. Save manual variations separately.

**Automated gate:** confirm owned mesh/modifier structure and a bounded evaluated geometry change. **Editor gate:** verify the control works, inspect topology/modifier order, and confirm unrelated content survives reset. **Visual gate:** silhouette remains understandable at preview scale.

**Limit:** a modifier check does not prove deformation-ready character topology or a production triangle budget. All geometry and numeric budgets are original fixtures rather than measured game assets.

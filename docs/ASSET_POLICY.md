# Asset and licensing policy

All bundled scenes are generated from original project code and original procedural texture motifs. Referenced games, videos, screenshots, fonts, and research downloads are study material, not bundled distributable assets.

Project source uses GPL-3.0-or-later. Blender and any optional capture/tool dependencies retain their own licenses. If adding external assets, record creator, canonical source, license, attribution, redistribution rights, modifications, and intended package location before bundling them. Do not assume a public download or a research mention grants redistribution rights.

Local generated `.blend`, renders, glTF, and recordings are intentionally excluded from source Git. They may carry names, paths, thumbnails, or embedded data that need review before publication. A release artifact must be built from an explicit public allowlist, never the parent workspace.

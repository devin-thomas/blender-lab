# Living roadmap

The six first labs establish a small editable pipeline. The items below are **specified opportunities**, not implemented or verified capabilities. Add a concrete card, original fixture, parameter, reset, scenario, and evidence gate before promoting an item.

|---|---|---|---|
| BL-007 | Modular environment kit | Assemble a corner, stair, and doorway from a shared atlas | Seams, silhouette, scene scale, export |

| BL-009 | Gradient-card atmosphere | Author local AO/shaft cards | Alpha sorting, camera angles, overdraw |
| BL-010 | Rig and deformation desk | Compare rigid segmented parts with a weighted mesh | Pose limits, weights, export skinning |

## Sequencing

First close the six-lab editor and evidence gates. Then prioritize environment kit, vertex shade, and Godot receiving station to make the authoring chain useful. Rigging, simulations, and compositing are separate slices with bounded compute budgets. Capture orchestration can grow alongside any slice without becoming a prerequisite to use it.

## Ticket template

Record problem, user action, editable mechanism, owned data, scenario, output contract, risks, acceptance layers, and evidence location. A broad capability name does not authorize a shallow placeholder. Select fewer experiments when needed to preserve an inspectable complete workflow.

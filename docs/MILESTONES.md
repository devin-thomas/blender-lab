# Delivery milestones

A milestone completes only when its selected implementation, outcome, recovery and appropriate editor/visual/downstream gates have evidence. The catalog's breadth is a plan, not a claim that all 96 labs run today.

## M0 - Verified editable foundation

Keep the six original local labs useful while the host and catalog grow.

Scope: BL-001, BL-002, BL-003, BL-004, BL-005, BL-006.

Exit gates:

- Preserve the current six-lab outcome/editor-smoke baseline on the recorded Blender build.
- Close core ownership/output/schema regressions before expansion.
- Keep screen capture, downstream import and production art acceptance separate.

Unavailable behavior: The original local builder/add-on subset stays available; missing expansion is stated honestly.

## M1 - Original retro authoring to a receiver

Build original modular form/surface/atmosphere, motion and useful export with bounded art and receiving-tool review.

Scope: BL-007, BL-008, BL-009, BL-010, BL-011, BL-012, BL-013, BL-014, BL-015, BL-016, BL-017, BL-018, BL-019, BL-020, BL-021, BL-022, BL-023, BL-024.

Exit gates:

- Qualify 007..009 kit/shade/cards before claiming a completed environment route.
- Implement rig/UV/bake/camera/simulation/asset/composite route in bounded slices.
- Run named Godot/material/animation acceptance and preserve artist ownership.

Unavailable behavior: Keep editable original source and Blender-only evidence when downstream/render profiles are unavailable.

## M2 - Geometry and graph mechanisms

Make topology, attributes, curves, shapes and node state directly inspectable and safely programmable.

Scope: BL-025, BL-026, BL-027, BL-028, BL-029, BL-030, BL-031, BL-032, BL-033, BL-034, BL-035, BL-036.

Exit gates:

- Validate manifold/domain/type/graph contracts and declared controls.
- Keep simulation/repeat/bake state boundaries versioned and recoverable.
- Verify socket/material migrations preserve unrelated user data.

Unavailable behavior: Use direct original data construction where context-sensitive or node-zone profiles are unavailable.

## M3 - Motion drawing and reconstruction

Combine original rigs, drawings, paint/sculpt and generated camera/plate evidence without guessing hidden implementation.

Scope: BL-037, BL-038, BL-039, BL-040, BL-041, BL-042, BL-043, BL-044, BL-045, BL-046, BL-047, BL-048, BL-049, BL-050.

Exit gates:

- Qualify trusted driver/IK/Action and baked sample contracts.
- Run actual editor context for Grease Pencil/sculpt/paint/clip operators.
- Compare tracking/calibration/mask outputs against known generated truth.

Unavailable behavior: Keep original reference geometry/poses/frames and label unsupported interactive operations.

## M4 - Production output and simulation

Deliver original short edits, materials, lighting, volume/hair and solver examples with measured output limits.

Scope: BL-051, BL-052, BL-053, BL-054, BL-055, BL-056, BL-057, BL-058, BL-059, BL-060, BL-061, BL-062, BL-063, BL-064, BL-065, BL-066, BL-067, BL-068.

Exit gates:

- Verify VSE timing/audio/caption/source identity and codecs.
- Qualify render passes/linking/alpha/world/normal/volume profiles separately.
- Preflight/cache/cancel simulations and review representative motion frames.

Unavailable behavior: Use cheap clean CPU/source previews and retain explicit GPU/codec/cache unavailable states.

## M5 - Asset pipelines and measured scale

Operate local batches, inspect real performance and move original assets across qualified formats.

Scope: BL-069, BL-070, BL-071, BL-072, BL-073, BL-074, BL-075, BL-076, BL-077, BL-078, BL-079, BL-080, BL-081, BL-082, BL-083, BL-084, BL-085, BL-086.

Exit gates:

- Qualify worker/device/profile and bounded count/memory/timing cases.
- Verify assets/linked data/units/view layers and package dependencies.
- Compare semantic subsets in USD/Alembic/FBX/OBJ/STL/vector/point-cloud/batch receivers.

Unavailable behavior: Use one qualified local format and small sequential jobs without compatibility claims for other profiles.

## M6 - Agent automation and durable delivery

Drive Blender through CLI, bpy, discovered MCP or a bounded service with recoverable, source-linked outcomes.

Scope: BL-087, BL-088, BL-089, BL-090, BL-091, BL-092, BL-093, BL-094, BL-095, BL-096.

Exit gates:

- Qualify each runtime/surface instead of treating them as interchangeable.
- Exercise authentication/schema/path/cancellation/checkpoint negative cases.
- Reproduce reviewed public artifacts offline and from clean source with truthful release gates.

Unavailable behavior: The local trusted CLI/source-only path requires no cloud account, MCP server, GPU or private repository.
